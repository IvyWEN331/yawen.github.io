# Ya Wen Homepage Update

This update changes the homepage styling and profile presentation.

Changes included:
- Replaces the homepage avatar with the new circular Cambridge portrait.
- Forces permanent dark mode and disables the light/dark switch.
- Changes typography to HugoBlox `system` sans-serif (Apple-like system font on macOS).
- Adds a `Teaching` tab to the top navigation.
- Makes the homepage name smaller.
- Displays the name as `Ya Wen 文雅`.
- Changes the role to `Research Associate`.
- Changes the affiliation line to `Postdoc in the University of Cambridge Department of Engineering`.
- Removes the GitHub social icon.
- Keeps LinkedIn, Google Scholar, and ORCID.
- Disables the bright gradient mesh on the hero.

## How to apply
1. Unzip this package.
2. Copy the folders `assets`, `config`, `content`, and `data` into your local `yawen.github.io` repository.
3. Choose Replace/Merge when macOS asks.
4. Open GitHub Desktop.
5. Confirm the changed files, then commit with a message such as:
   `Update homepage profile and dark theme`
6. Push origin.
7. GitHub Actions will deploy the new version automatically.

Important:
The LinkedIn, Google Scholar, and ORCID URLs are still placeholders/generic links because the real profile URLs have not been supplied yet.
